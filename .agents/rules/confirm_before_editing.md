# Regla de Flujo de Trabajo: Confirmación previa requerida

De ahora en adelante, para cada solicitud o instrucción del usuario:
1. **NO modificar código ni archivos inmediatamente**.
2. **Responder primero en el chat**:
   - Confirmar si se ha entendido la solicitud exactamente.
   - Explicar brevemente la solución o los cambios que se proponen realizar.
   - Solicitar la confirmación / visto bueno del usuario.
3. **Ejecutar cambios únicamente tras recibir el visto bueno explícito del usuario**.
4. Modifica el codigo directamente sin preguntar en el caso de que sean ordenes simples como "elimina esto o lo otro", "crea tal archivo", etc
